# 📱 Fonrio - Sistema de Gestión de Inventarios

**Fonrio** es una solución digital integral desarrollada como proyecto de grado para el programa de Análisis y Desarrollo de Software (ADSO) del SENA. Está diseñada específicamente para optimizar la administración de inventarios en negocios de tecnología (venta de celulares y accesorios), facilitando un control preciso y en tiempo real.

Este proyecto fue desarrollado bajo una metodología de trabajo colaborativo por un equipo de 4 desarrolladores, donde participé activamente en el diseño de la arquitectura de software, gestión de tareas y control de versiones.

## 🚀 Características Principales

El sistema permite a los administradores y empleados manejar todo el ciclo de vida del comercio:
*   **📦 Gestión de Productos:** Clasificación detallada de celulares (Gama baja, media, alta) y accesorios (Audio, Protección, Carga).
*   **👥 Control de Empleados:** Creación, actualización y eliminación de usuarios con asignación de roles y estados.
*   **🤝 Módulo de Proveedores:** Registro y gestión directa de los proveedores del negocio.
*   **🛒 Operaciones Comerciales:** Registro transaccional de Compras, Ventas y Devoluciones.

## 🛠️ Tecnologías y Arquitectura

El proyecto está construido utilizando un enfoque de separación de responsabilidades (Backend/Frontend):

*   **Backend:** Java (Spring Boot)
    *   *Arquitectura MVC:* Uso de Controllers, Services y DTOs para un manejo limpio de los datos.
    *   *Persistencia:* Spring JDBC Template para consultas SQL y manipulación de la base de datos.
*   **Frontend:** PHP, HTML5, CSS3
    *   Interfaces dinámicas e intuitivas adaptadas a las necesidades de los vendedores.
*   **Base de Datos:** Relacional (MySQL / SQL).
*   **Control de Versiones y Trabajo en Equipo:** Git & GitHub.

## 💡 Propósito del Proyecto (Misión)
Facilitar el registro de productos, compras, ventas y devoluciones en un entorno intuitivo, ayudando a las pequeñas y medianas empresas a reducir pérdidas por desorganización y a mejorar su toma de decisiones.
